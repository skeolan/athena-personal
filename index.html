Athena Personal

Athena Personal is a private, single-user planning assistant. Its owner built it for their own use. It is not offered to the public, and nobody else can sign in to it.

What it does

  • Reads the owner's selected Google calendars (read-only) to prepare a short daily briefing.
  • Reads the owner's selected Google Tasks lists to include tasks in that briefing.
  • Changes a Google task (create, reschedule, complete, or edit) only after the owner approves that exact change. It never deletes tasks.

It runs on the owner's own computer, and may later send scheduled reminders from the owner's private GitHub repository.
